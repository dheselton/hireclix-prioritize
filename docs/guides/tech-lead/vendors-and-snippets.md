# Vendors & snippets

**When to use this** — Escalating to Webflow/iPaaS/etc., or maintaining reusable career-site code.

## Steps

1. Open [Vendors](/pm/vendors). Create or update an escalation tied to the live site or project.
2. Keep status current until the vendor closes the loop; link related tasks when useful.
3. Open [Snippets](/snippets) to find or update shared code.
4. Use the **Incidents** tab when a snippet breaks in production — that creates linked work to fix it.
5. Prefer Loom explainers (sidebar **Loom Library**) for visual how-tos your team already recorded.

## Done when

Vendor tickets have clear next steps and snippet/incident work is assigned.

## If this happens

- **No Vendors nav** — you need developer or tech_lead (or PM/BA) access.
- **No Snippets** — designer, developer, or tech_lead role required (or multi-role with one of those).
