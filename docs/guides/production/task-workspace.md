# Task workspace

**When to use this** — Updating a single task’s status, dates, people, or attachments.

## Steps

1. Open a task from [Daily Briefing](/), [All Work](/pm/work), or a project’s Tasks tab (full page: `/pm/tasks/...`).
2. Update **status**, description, and attachments as needed.
3. Change **Start / Due** only when the plan changed — review **Cascade Confirm** before applying.
4. Reassign via the assignee control if ownership moved.
5. Leave a clear comment when you block or hand off.

## Done when

The task reflects reality (owner, dates, status) and downstream people aren’t surprised by a silent cascade.

## If this happens

- **Cascade list looks wrong** — cancel, check dependencies on the project Timeline, then retry or ask PM to recalc from kickoff.
- **Can’t see the task** — you may not be a member/assignee; ask to be added on the project Overview Team card.
