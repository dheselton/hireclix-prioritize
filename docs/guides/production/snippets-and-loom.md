# Snippets & Loom

**When to use this** — Reusing career-site code, tracking broken snippets, or finding recorded walkthroughs.

## Steps

1. Open [Snippets](/snippets). Search by name or site context before inventing a new block.
2. Update an existing snippet when the pattern changed; leave notes teammates will understand.
3. On the **Incidents** tab, log a broken snippet so a linked task is created and tracked.
4. Use the sidebar **Loom Library** (external careersite-ops link) for visual how-tos.
5. **Developers:** escalate vendor-owned breakage on [Vendors](/pm/vendors) when the fix isn’t in our code.

## Done when

The right snippet (or incident) is current, and Loom is used instead of re-explaining solved problems.

## If this happens

- **No Snippets / Loom in the nav** — need designer, developer, or tech_lead on your account (PM/BA alone is not enough for Loom).
