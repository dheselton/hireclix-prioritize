# Clients, forms & portal

**When to use this** — Client setup, intake forms, or sharing progress with external contacts.

## Steps

1. Manage accounts on [Clients](/pm/clients) (brands, environments, logos as needed).
2. Review or edit intake forms on [Forms](/pm/forms). Use the Form Builder only when changing fields or publishing a new slug.
3. Share the public link `/f/<slug>` (or embed) with requesters.
4. On a project, invite portal contacts (token link) so they can use `/portal/...` without logging into Prioritize.
5. Post **client-visible** comments when the external audience should see an update.

## Done when

The right form is live, the client record is accurate, and portal invitees can see status/messages.

## If this happens

- **Portal link expired / revoked** — re-invite from the project portal controls.
- **Form not submitting** — confirm publish state and that the edge form API is reachable; test in a private window.
