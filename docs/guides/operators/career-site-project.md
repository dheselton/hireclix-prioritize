# Career site project (operators)

**When to use this** — Standing up or steering a greenfield Career Site build.

## Steps

1. Confirm the Career Site [template](/pm/templates) (durations, roles, dependencies, page groups) is current — see the [Career site deep-dive](/pm/help?guide=_shared/career-site-build).
2. Create a project from that template (client + go-live).
3. On the project, **Configure Timeline** → set kickoff → **Recalculate**.
4. After Discovery, add pages on the **Pages** tab so reserved time is consumed.
5. Staff designers/devs on the Overview **Team** card and assign tasks.
6. When build/QA is done, enter **Support mode** so the project becomes a Live Career Site.

## Done when

Schedule reflects kickoff/go-live, pages are defined or still reserved on purpose, and owners are clear through launch.

## If this happens

- **Cascade does nothing** — use **Diagnose timeline**; you need dependencies and a kickoff.
- **Need the full walkthrough** — open [Career site deep-dive](/pm/help?guide=_shared/career-site-build).
